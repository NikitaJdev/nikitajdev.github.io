# Nikita | Websites for local businesses

Hand-coded websites for cafés, car detailers and local shops in Northampton.

- **Portfolio:** `index.html`
- **Corner Café** (concept): `corner-cafe/` – coffee shop with live opening hours, weekly specials and order-ahead on WhatsApp
- **OBSIDIAN Auto Detailing** (concept): `obsidian/` – detailing site with a gallery lightbox and WhatsApp quote requests

Built with plain HTML, CSS and JavaScript. No frameworks, no website builders.
